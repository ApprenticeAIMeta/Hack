# footage/

Raw recordings go here (gitignored). `tools/new_procedure.sh` copies or pulls each take into this folder
as `<name>_expert1.mp4`, `<name>_expert2.mp4` and compiles from them.

The thermocouple expert's take ships in smaller form as `procedures/thermocouple/expert_take.mp4`,
which the `/build` page plays when this folder is empty.
