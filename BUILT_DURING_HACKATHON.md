## Written during the event

Everything in this repository: the compile pipeline, progress model, step tracker, live server,
dashboard, guide screen, Android app logic, eval harness and docs.

## Existing before the event

- Pairing the Ray-Ban Meta glasses with a Pixel 10, running Meta's open-source Device Access Toolkit
  CameraAccess sample, and measuring stream settings. That code is not in this repository.
- The Android project's Gradle setup is adapted from that sample.
- Test footage recorded on Oct 22, used only for development. It is not in this repository, and the
  submitted demo uses footage recorded during the event.

## Open source used

Meta Device Access Toolkit, meta-sam-parser, DINOv2 weights, FastAPI, PyAV, OpenCV, NumPy, PyTorch,
Transformers, OkHttp and Jetpack Compose. Fonts: Barlow and Barlow Condensed.
